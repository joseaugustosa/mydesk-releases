# MyDesk — releases (PC + Android)

Repositório **público** só para instalar e atualizar a app.

| Plataforma | Ficheiro na [Release](https://github.com/joseaugustosa/mydesk-releases/releases/latest) |
|------------|----------------------------------------------------------------------------------------|
| **Windows** | `MyDesk-Setup-x.x.x.exe` |
| **Android** | `MyDesk-x.x.x.apk` |

A app lê `mydesk-update.json` neste repo para avisar de novas versões.

Código fonte: repo privado `mydesk` (GitHub).
